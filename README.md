# Sayonita Das - HR Portfolio

Static personal portfolio website built with:

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks.
No backend.
No database.
No npm packages required.

## Required personal files

Place Sayonita's photograph here:

assets/images/profile.webp

Recommended:
- WebP
- portrait orientation
- about 700 x 800 pixels
- under 200 KB if possible

Place the resume here:

resume/Sayonita-Das-Resume.pdf

## Important information to edit

Open index.html and replace:

- Email
- Phone number
- LinkedIn URL
- Instagram URL if needed
- Exact internship dates
- Company details
- Education details
- Certification details

## Run locally

You can simply open index.html.

For a better local server:

Python:
python -m http.server 5500

Then visit:

http://localhost:5500

## GitHub Pages

1. Push the project to GitHub.
2. Open repository Settings.
3. Open Pages.
4. Choose:
   Deploy from a branch
5. Select:
   main
6. Select:
   /root
7. Save.

The site will then become available through GitHub Pages.
